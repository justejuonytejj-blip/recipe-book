# Recipe Book – AI darbo taisyklės

## Projekto kontekstas
„Recipe Book“ – asmeninis receptų katalogas, kuriame vartotojai galės užsiregistruoti, prisijungti ir saugoti bei valdyti tik savo receptus.

## Naudojamos technologijos
- React
- JavaScript (JSX)
- Vite
- CSS
- Supabase (bus prijungta vėliau)
- GitHub

## Pagrindinės darbo taisyklės
1. Vienu metu atlik tik vieną mažą užduotį.
2. Neįgyvendink papildomų funkcijų, kurių neprašiau.
3. Prieš keisdamas kodą trumpai paaiškink, ką keisi.
4. Keisk tik tuos failus, kurie būtini konkrečiai užduočiai.
5. Neištrink esamo veikiančio kodo be būtinos priežasties.
6. Nekeisk nereikalingų failų.
7. Nedaryk Git commit automatiškai – commit daryk tik kai paprašysiu.
8. Po kiekvieno žingsnio sustok ir palauk tolesnių nurodymų.
9. Nekurk naujų Git branch be prašymo.
10. Nepridėk naujų bibliotekų ar priklausomybių be aiškaus leidimo.
11. Visą vartotojo sąsajos tekstą rašyk lietuvių kalba.

## Dizaino taisyklės
- Išlaikyk modernų, elegantišką ir minimalistinį stilių.
- Pagrindinės spalvos: kreminė, smėlio, balta ir alyvuogių žalia.
- Antraštėms naudok elegantišką serif tipą; tekstui – paprastą, lengvai skaitomą šriftą.
- Naudok švelniai užapvalintus kampus ir subtilius šešėlius.
- Nekeisk esamo dizaino be aiškaus prašymo.

## MVP funkcionalumai
- Registracija ir prisijungimas.
- Receptų pridėjimas.
- Receptų peržiūra.
- Receptų redagavimas.
- Receptų ištrynimas.
- Receptų saugojimas Supabase duomenų bazėje.
- Kiekvienas vartotojas matys tik savo receptus.

## Saugumas
- Vartotojas gali matyti ir valdyti tik savo receptus.
- Nesaugok slaptažodžių, API raktų ar kitų slapų duomenų kode.
- Supabase prisijungimo duomenis laikyk aplinkos kintamuosiuose (`.env`), o ne projekto faile, kuris keliauja į GitHub.
- Neįgyvendink autentifikacijos ar duomenų bazės logikos anksčiau laiko, jei to neprašiau.

## Darbo eiga
1. Atlik tik vieną mažą užduotį.
2. Trumpai paaiškink, ką pakeitei.
3. Sustok ir palauk mano patvirtinimo arba kitos užduoties.
4. Commit ir branch kurk tik tada, kai to aiškiai paprašysiu.
