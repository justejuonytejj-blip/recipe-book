# Recipe Book – AI darbo taisyklės

## Projekto kontekstas
„Recipe Book“ – asmeninis receptų katalogas, kuriame vartotojai galės užsiregistruoti, prisijungti ir saugoti bei valdyti tik savo receptus.

## Naudojamos technologijos
- React
- JavaScript (JSX)
- Vite
- CSS
- Supabase (bus prijungta vėliau)
- GitHub

## Pagrindinės darbo taisyklės
1. Vienu metu atlik tik vieną mažą užduotį.
2. Neįgyvendink papildomų funkcijų, kurių neprašiau.
3. Prieš keisdamas kodą trumpai paaiškink, ką keisi.
4. Keisk tik tuos failus, kurie būtini konkrečiai užduočiai.
5. Neištrink esamo veikiančio kodo be būtinos priežasties.
